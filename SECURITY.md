# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of BootCamp Performance Control.

## Reporting a Vulnerability

Please do not report security-sensitive vulnerabilities in a public GitHub issue.

Use GitHub private vulnerability reporting when available.

If private vulnerability reporting is unavailable, please report security-sensitive issues by email to security@mkus.co.uk.

Security reports should include:

- the affected version,
- the affected Mac model and Windows version when relevant,
- steps to reproduce the issue,
- the expected and observed behaviour,
- any relevant logs with personal or sensitive information removed.

## Hardware Safety

BootCamp Performance Control interacts with Windows processor power-management settings.

Reports involving unexpected power-setting changes, failed Restore operations, or hardware-specific behaviour are treated as safety-relevant issues.
